# Backend API — quick reference for frontend devs

Interactive docs (auto-generated by FastAPI) are available at **`http://localhost:8000/docs`** once the server is running.

---

## Running locally

```bash
docker build -t moon-backend .
docker run -p 8000:8000 moon-backend
```

Or without Docker:

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

The server listens on **port 8000**. The Vite dev proxy already forwards `/api/*` → `http://localhost:8000`, so from the frontend you call `/api/positions/surface`.

---

## POST /positions/surface

Computes Sun and Earth positions as seen from a point on the Moon's surface, plus solar insolation at that point.

### Request

`Content-Type: application/json`

```json
{
  "utc":     "2026-10-18T05:15:00",
  "lat_deg": -89.9,
  "lon_deg": 0.0,
  "alt_km":  0.0
}
```

| Field | Type | Constraints | Description |
|---|---|---|---|
| `utc` | string | ISO 8601, no timezone suffix needed | Moment in time to query |
| `lat_deg` | float | −90 … 90 | Planetographic latitude on the Moon |
| `lon_deg` | float | −180 … 180 | Planetographic longitude on the Moon (east positive) |
| `alt_km` | float | ≥ 0, **optional** (default `0.0`) | Height above the lunar surface in km |

### Response

```json
{
  "earth": {
    "azimuth_deg":   312.47,
    "elevation_deg":  14.82,
    "range_km":   384400.0,
    "lighttime_s":    1.281
  },
  "sun": {
    "azimuth_deg":   178.03,
    "elevation_deg":   2.15,
    "range_km":  149600000.0,
    "lighttime_s":  498.7
  },
  "insolation": {
    "insolation_watts": 1243.6,
    "insolation_graph": [
      { "utc": "2026-09-03T05:15:00", "insolation_watts": 0.0 },
      { "utc": "2026-09-03T06:15:00", "insolation_watts": 312.1 },
      "..."
    ]
  }
}
```

#### `earth` / `sun` fields

| Field | Unit | Description |
|---|---|---|
| `azimuth_deg` | degrees, 0–360, N = 0 clockwise | Horizontal direction to the body from the observer |
| `elevation_deg` | degrees, −90 … 90 | Angle above (+) or below (−) the horizon; negative = below horizon |
| `range_km` | km | Distance from observer to body centre |
| `lighttime_s` | seconds | One-way light travel time (already applied to the position via `LT+S` aberration correction) |

#### `insolation` fields

| Field | Unit | Description |
|---|---|---|
| `insolation_watts` | W/m² | Instantaneous solar flux at the queried time and location. `0` when the Sun is below the horizon. Maximum ≈ 1367 W/m² |
| `insolation_graph` | array | Time series spanning **±1 lunar day** (~29.5 Earth days each side) centred on the queried time, sampled every **1 hour**. Expect **~1 416 points**. Each element: `{ "utc": "<ISO string>", "insolation_watts": <float> }` |

### Errors

| Status | Meaning |
|---|---|
| `400` | Bad request — invalid UTC string, out-of-range coordinates, or SPICE kernel coverage gap. The `detail` field in the JSON body contains the raw error message. |

### fetch() example

```ts
const res = await fetch("/api/positions/surface", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    utc:     "2026-10-18T05:15:00",
    lat_deg: -89.9,
    lon_deg: 0.0,
    alt_km:  0.0,
  }),
});

if (!res.ok) {
  const { detail } = await res.json();
  throw new Error(detail);
}

const data = await res.json();
// data.sun.elevation_deg      → is the Sun above the horizon?
// data.insolation.insolation_watts → current W/m²
// data.insolation.insolation_graph → array for chart rendering
```

### Notes

- Elevation > 0 means the body is visible from that surface point.
- The `insolation_graph` array is large (~1 400 items). If you only need the scalar value, you can still read `insolation.insolation_watts` and ignore the graph array — the backend always computes both.
- All positions are computed in the `MOON_ME` (Moon Mean Equator) body-fixed frame using DE440 ephemeris kernels.
